WHAT IS LIFE IS TECH! LESSON

ライフイズテック レッスンとは

中学校の情報・技術教育に対応したデジタル学習教材です。生徒が画面上で学びを進めやすく、先生は授業準備や進捗確認を行いやすい構成になっています。

  • ブラウザで利用でき、学校の端末で始めやすい
  • 情報モラル、Web制作、計測・制御、AIなどを幅広く学べる
  • 指導案・授業スライド・参考動画など先生向け支援も活用できる
  • 詳しい教材内容は公式サイトで確認可能

ABOUT THE LESSON

情報モラルから、Web制作・計測制御・AIまで。

「情報の技術」を知識として学ぶだけでなく、問題解決の流れに沿って、実際に手を動かしながら理解を深めやすい教材です。

D(1) INFORMATION

情報モラル・情報リテラシー

情報の安全な活用や、生活・社会を支える情報技術について学び、考える力につなげます。

D(2) WEB / PROGRAMMING

Webコンテンツの制作

HTML・CSS・JavaScriptなどを使い、ネットワークを利用した問題解決を体験します。

D(3) MEASUREMENT / CONTROL

計測・制御のプログラミング

GIGA端末のカメラやスピーカーも活用し、計測・制御の仕組みとプログラミングを学びます。

D(4) AI / SOCIETY

AIのしくみと活用

AIの基本的な仕組みや活用例を学び、情報技術と社会の関わりについて考えます。

より詳しい教材内容・動作環境は ライフイズテック レッスン公式サイト ↗ をご覧ください。

FOR STUDENTS / TEACHERS

生徒が進めやすい。先生も授業を組み立てやすい。

生徒用教材だけでなく、先生の授業準備・授業進行・理解度確認を支えるツールが用意されています。

生徒にとって

自分のペースで、つくりながら学ぶ。

  • ✓教材内のナビゲーションに沿って、自分の進度で学習を進めやすい。
  • ✓入力したコードの結果をその場で確認しながら、理解を深めやすい。
  • ✓理解度チェックなどを使い、学んだ内容を振り返ることができる。
  • ✓授業だけでなく、学校の方針に応じて自学習にも活用しやすい。
先生にとって

準備から進捗確認まで、授業を支える。

  • ✓指導案・授業投影用スライド・参考動画などを活用できる。
  • ✓生徒ごとの進捗や理解度を管理画面で確認できる。
  • ✓プログラミングに不安がある先生でも、授業を始めやすい。
  • ✓D(1)〜D(4)を学校の授業計画に合わせて組み合わせて使いやすい。
