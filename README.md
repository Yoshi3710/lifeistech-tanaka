# tanaka-lifeistech-pilot-v8

v6を基準に、ページトップだけを強化した版です。

## 今回の変更点
- v7は破棄
- v6の構成・文章・画像分散配置を基本維持
- ページトップに大きな写真を使用し、インパクトを強化
- ページトップ付近に「Life is Tech! Lesson / ライフイズテック レッスン（中学）」を明確に表示
- 同じエリアに「株式会社タナカ（取扱会社）」を表示
- 申込みフォーム、印刷、送信処理はv6から変更なし

## 公開方法
1. GitHubにこのフォルダ内のファイルをすべてアップロード
2. `Settings` → `Pages`
3. `Deploy from a branch`
4. `main` / `(root)` を指定して保存
